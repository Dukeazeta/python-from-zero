Name a piece of code, use it anywhere

In real life

A recipe card titled "pancakes" lists the steps once. After that, whenever anyone says "make pancakes", you follow the card. You don't rewrite the steps each time, and if you improve the recipe, every future batch gets better.

A function is a named block of code. You write it once with def (short for "define"), and then call it by name, as many times as you like.{{cite:1}}{{cite:5}}

greet.py
def greet():
    print("Hello!")
    print("Welcome to the course.")

greet()
greet()
ShowsHello! Welcome to the course. Hello! Welcome to the course.

Defining the function doesn't run it; it just writes the recipe card. The lines inside run only when you call greet(), with the parentheses. Same colon-and-indent rule as if and loops.

Giving a function something to work with

Recipes often say "for n people". A function can take values too. The names in the def line's parentheses are parameters: variables that get filled in when the function is called. The values you pass in the call are arguments.{{cite:2}}

greet_name.py
def greet(name):
    print(f"Hello, {name}!")

greet("Ada")
greet("Chidi")
ShowsHello, Ada! Hello, Chidi!

In the first call, the argument "Ada" goes into the parameter name. In the second, name holds "Chidi". Separate several parameters with commas: def area(width, height):.

New words

def
Starts a function definition.
Call
Run a function by writing its name and parentheses: greet().
Parameter
A variable in the def line that receives a value.
Argument
The value you pass in when calling: in greet("Ada"), "Ada".

Handing back an answer with return

In real life

Asking a friend to work something out: "What's 15% of 8,000?" A good friend tells you the answer so you can use it: add it to the bill, write it down. A friend who just mutters it to themselves hasn't really helped.

return ends the function and hands a value back to wherever it was called.{{cite:3}} The call then becomes that value, so you can store it, print it, or use it in a bigger expression:

tip.py
def tip(bill):
    return bill * 0.15

amount = tip(8000)
print(amount)
print(8000 + tip(8000))
Shows1200.0 9200.0

return is not print

print shows something on the screen for a person to read. return hands a value back to the code, so the program can keep using it. A function that prints its answer instead of returning it is the friend who mutters: you see the number, but the program can't do anything with it.

A function with no return gives back a special value called None, meaning "nothing".{{cite:4}} If you ever see None where you expected an answer, check whether your function prints instead of returning.

Functions are how LeetCode works

Every LeetCode problem asks you to fill in a function. It calls your function with test inputs and checks what you return, not what you print. From now on, the exercises check your functions the same way: the tests call your function with several arguments and compare the results.

New words

Return value
The value a function hands back with return.
None
A value meaning "nothing". Functions without return give it back.

Try it: rectangle area

Write a function area(width, height) that returns the area of a rectangle (width times height). Don't print inside the function. The tests call it for you.

What is pass, and why does it say "got None"?

pass means "do nothing"; it's a placeholder so the function isn't empty. A function that does nothing returns None. Replace pass with return width * height.

Try it: is_even

Write is_even(n) that returns True if n is even and False otherwise.

A shorter way

You can use if / else with two returns, which is fine. But n % 2 == 0 is already True or False, so return n % 2 == 0 does it in one line.

Try it: count_vowels

Write count_vowels(text) that returns how many vowels (a, e, i, o, u) the text contains, counting capitals too. count_vowels("Banana") returns 3.

Stuck? A hint

Loop over text.lower() so capitals become lowercase. For each letter, if letter in "aeiou": add one to count. The return is already there, after the loop.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. In def greet(name): and the call greet("Bo"), what is "Bo"?

The value passed in a call is the argument. name, in the def line, is the parameter that receives it.

2. A function prints its answer but has no return. What does x = f() store?

Without return, a function gives back None. Printing only shows the answer; it doesn't hand it back.

3. When do the lines inside a def run?

def just defines the function. Its body runs on each call.

4. What does LeetCode check about your function?

LeetCode calls your function and compares its return value with the expected answer.
