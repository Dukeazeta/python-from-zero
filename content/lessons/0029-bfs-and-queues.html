First come, first served

In real life

A queue at the bank: new people join at the back, and the person at the front is served next. Unlike a stack of plates, whoever has waited longest goes first.

A queue adds at the back and removes from the front: FIFO, first in, first out.{{cite:1}} You could use a list, but list.pop(0) shifts every remaining item along one place, so it's O(n).{{cite:2}} Python's collections.deque (say "deck") is built for this: append() adds at the back and popleft() removes from the front, both O(1).{{cite:3}}

bank.py
from collections import deque

queue = deque(["Ada", "Bo"])
queue.append("Chi")          # Chi joins the back
print(queue.popleft())       # Ada is served first
print(list(queue))          # list() copies the queue into a plain list for printing
ShowsAda ['Bo', 'Chi']

Breadth-first search: level by level

In real life

Drop a stone in a pond: the ripple reaches everything one step away, then everything two steps away, then three. Or spreading news: you tell your friends, they tell their friends, and so on. Everyone at distance 1 hears before anyone at distance 2.

Breadth-first search (BFS) visits nodes in order of how far they are from the start.{{cite:4}} On a tree that means level by level: the root, then its children, then grandchildren. The queue makes it work: take a node from the front, then add its children to the back. Children always wait behind everyone already queued at the level above.

To know where one level ends, look at the queue's length at the start of each level: that many nodes belong to this level. Process exactly that many, and anything added meanwhile is the next level.

levels.py
queue = deque([root])
while queue:
    level_size = len(queue)
    for _ in range(level_size):
        node = queue.popleft()
        # ...use node...
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    # one whole level is done here

DFS (Lesson 28) is natural with recursion; BFS is natural with a queue. Both visit each node once: O(n). Choose BFS when "nearest first" matters.

Stuck? A hint

Use the shape above. At the start of each level make an empty level list, append each node's value to it inside the for, and after the for append level to result.

Why BFS finds the shortest

Because BFS reaches everything at distance 1 before anything at distance 2, the first time it finds what it's looking for, it has found the closest one. LeetCode 111 asks for the minimum depth: the number of nodes from the root down to the nearest leaf.{{cite:7}} DFS would have to explore every branch to be sure. BFS can stop at the very first leaf it meets.

LeetCode 111: Minimum Depth of Binary Tree

Return the number of nodes on the shortest path from the root to a leaf. Use BFS and return as soon as you take a leaf off the queue. A node with only one child is not a leaf.

Stuck? A hint

The queue holds (node, depth) tuples. Pop one and unpack it. If both children are None, it's a leaf: return depth. Otherwise queue each existing child with depth + 1.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. Why use deque.popleft() instead of list.pop(0)?

Removing a list's first item shifts all the others along.

2. A stack is LIFO. What is a queue?

Like a queue at the bank, whoever arrived first leaves first.

3. In level-order BFS, what tells you how many nodes are on the current level?

At that moment the queue holds exactly one level; children added during it belong to the next.

4. Why can BFS stop at the first leaf in Minimum Depth?

BFS goes level by level, so the first leaf found is on the shallowest level with a leaf.
