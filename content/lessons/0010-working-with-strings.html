A string is a row of characters

In real life

A bead necklace with a letter on each bead: the beads are in a fixed order, and you can point at "the third bead" or "the last three beads". That's a string.

Everything you learned about list indexes and slices works on strings too.{{cite:1}} Each character has an index starting at 0:

beads.py
word = "python"
print(word[0])      # first character
print(word[-1])     # last character
print(word[0:3])    # slice: index 0 up to (not including) 3
print(len(word))

Slices with a step

A slice can take a third number, the step, just like range: word[::2] takes every second character.{{cite:4}} A step of -1 walks backwards, so word[::-1] is the whole string reversed: "python"[::-1] is "nohtyp". Remember that one; you'll use it in a minute.

Strings can't be changed in place

Unlike a list, you can't swap one character: word[0] = "J" gives TypeError: 'str' object does not support item assignment. Strings are immutable: once made, they never change.{{cite:3}} Instead, you build a new string and store it, for example word = "J" + word[1:].

String methods: tools for text

In real life

A photocopier with buttons: "enlarge", "lighten", "remove the margins". You put in a page and get a new, changed copy. The original page is untouched.

Strings come with dozens of methods.{{cite:5}} Because strings are immutable, each one gives back a new string and leaves the original alone, so store the result if you want to keep it.{{cite:2}} The ones you'll use most:

Why cleaning matters

People type messily: " Yes", "YES", "yes ". Comparing any of those with == "yes" gives False. The fix is to clean the answer first: answer.strip().lower() == "yes".

Palindromes

In real life

"Racecar", "level", "noon": words that read the same forwards and backwards, like a road that looks identical whichever end you start from.

A palindrome reads the same backwards. With [::-1], checking one is a single comparison: word == word[::-1]. Real phrases need cleaning first: "Never odd or even" is a palindrome only once you ignore spaces and capitals. That version is LeetCode problem 125, which you'll solve properly in Lesson 21.

Try it: palindrome checker

Ask Phrase? . Ignoring capitals and spaces, print Palindrome if it reads the same backwards, otherwise Not a palindrome.

Stuck? A hint

Make a cleaned copy first: lowercase, and with spaces replaced by nothing, .replace(" ", ""). Then compare the cleaned copy with its reverse.
