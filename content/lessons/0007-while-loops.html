Keep going while it's true

In real life

"Stir the soup while it's still lumpy." You stir, look, and if it's still lumpy you stir again. The moment it's smooth, you stop. You didn't decide in advance how many times to stir; you kept checking.

A while loop repeats its block as long as its condition is True. It checks the condition, runs the block, then goes back up and checks again. When the condition becomes False, Python carries on with the code after the loop.{{cite:1}}{{cite:4}} A loop is any code that repeats, and each pass through it is called an iteration.

count.py
count = 1
while count <= 3:
    print(count)
    count = count + 1
print("Done")
Shows1 2 3 Done

Follow it like the computer does. count is 1; is 1 <= 3? Yes: print 1, make count 2. Is 2 <= 3? Yes: print 2, make it 3. Is 3 <= 3? Yes: print 3, make it 4. Is 4 <= 3? No: leave the loop and print "Done".

This shape is called the counter pattern: a variable that starts somewhere, gets checked, and changes inside the loop.

The loop that never ends

Delete the line count = count + 1 and count stays 1 forever, so 1 <= 3 is always true and the loop never stops. That's an infinite loop.{{cite:1}} In these exercises, code that runs longer than 6 seconds is stopped for you. In a terminal, press Ctrl + C to stop it.

The rule that prevents it: something inside the loop must change, so the condition can eventually become false.

A shortcut: +=

count += 1 means exactly the same as count = count + 1. There are matching shortcuts -=, *= and /=.{{cite:3}} You'll see += everywhere from now on.

New words

Loop
Code that runs again and again.
Iteration
One pass through a loop's block.
Infinite loop
A loop whose condition never becomes false, so it never stops.
+=
Add to a variable: x += 2 is x = x + 2.

Using a while loop, print 5, 4, 3, 2, 1 on separate lines, then Liftoff!.

Stuck? A hint

Keep going while n is at least 1. Inside: print n, then make it one smaller with n -= 1. Print Liftoff! after the loop, not indented.

Ask until the answer is right

In real life

A cash machine asks for your PIN. Wrong? It asks again. It keeps asking until it gets the right one. The number of tries isn't known in advance: that's exactly when a while loop fits.

A while loop suits checking input. Ask once before the loop, then keep re-asking while the answer is wrong:

yes_no.py
answer = input("Continue (yes/no)? ")
while answer != "yes" and answer != "no":
    answer = input("Please type yes or no: ")
print("Thanks, you said " + answer)
Shows (typed maybe, then no)Continue (yes/no)? maybe Please type yes or no: no Thanks, you said no

Try it: the vault

Ask Password: . While the answer isn't swordfish, print Wrong. Try again. and ask Password: again. Once it's right, print Vault open.

Stuck? A hint

The structure is: ask once before the loop; while password != "swordfish":; inside the loop print the warning and ask again (storing the new answer in the same variable); after the loop, open the vault.

Try it: a shop till

Keep asking Price (0 to finish)? and add each price to a running total. When they type 0, stop and print Total: followed by the total. For 500, 1200, 300, 0 it shows Total: 2000.

Stuck? A hint

Same shape as the vault: ask once before the loop, loop while the price isn't 0, and inside the loop add the price to total before asking again. Remember int().

Leaving early with break

In real life

Searching through drawers for your keys: you check drawer after drawer, but the moment you find them, you stop. You don't keep opening drawers just because there are more.

break ends a loop immediately, wherever it is in the block. It's often paired with while True:, a loop whose condition is always true, so the only way out is a break.{{cite:2}} This shape reads nicely when the "should I stop?" question comes in the middle of the loop:

echo.py
while True:
    word = input("Say something (or quit): ")
    if word == "quit":
        break
    print("You said " + word)
print("Bye")

Its partner, continue, skips the rest of the current iteration and jumps straight back to the condition check.{{cite:2}} You'll need continue less often, but now you'll recognise it.

New words

break
Leave the loop right now.
continue
Skip to the next iteration of the loop.

Try it: guess the number

The secret number is 7. Use while True: to keep asking Guess? . Print Too low or Too high for wrong guesses. When they get it, print Got it! and break.

Stuck? A hint

Inside while True:, ask for a guess and convert it. Then an if / elif / else: lower than secret, higher than secret, or right. Put break inside the "right" block, indented under the print.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. How many times does this print? n = 0, then while n < 3: with print(n) and n += 1 inside.

It prints 0, 1 and 2. When n becomes 3, 3 < 3 is false and the loop ends.

2. Most common cause of an infinite loop?

If nothing inside the loop affects the condition, a true condition stays true forever.

3. What does break do?

break leaves the loop; the program carries on after it. continue is the one that skips to the next iteration.

4. After x = 10 and x -= 3, what is x?

x -= 3 is short for x = x - 3.
