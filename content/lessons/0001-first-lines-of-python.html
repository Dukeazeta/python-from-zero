A program is a list of instructions

A computer does nothing on its own. It follows instructions, one after another, exactly as they are written. A set of instructions is called a program, and the instructions themselves are called code.

Python is a language for writing those instructions. The official tutorial describes it as easy to learn.{{cite:1}} Python reads your code from the top line to the bottom line and carries out each one in turn.

Your first instruction: print

The first instruction to learn is print. It tells Python to show something on the screen. Here is one complete line of Python:

print is a function: a named instruction that does one job. You use a function by writing its name followed by parentheses ( ). Whatever goes inside the parentheses is what the function works with.

Text always goes inside quotes, so Python knows where it starts and stops. Python calls a piece of text a string, as in a string of characters. Double quotes "Hello" and single quotes 'Hello' work the same way.{{cite:2}}

Why the order matters

Python runs lines from top to bottom, so whatever you print first appears first. Swap your two lines and press Run to see it.

Python can do maths

Numbers work differently from text. Write a number without quotes and Python treats it as a number it can calculate with. Compare these two lines:

no_quotes.py
print(2 + 3)
Shows5
quotes.py
print("2 + 3")
Shows2 + 3

The quotes make the difference. Inside quotes, 2 + 3 is just text, so Python shows it exactly as written. Without quotes, Python works out the answer first and shows that.

Something Python can work out, like 2 + 3, is called an expression. Expressions are made of values (like 2 and 3) and operators (like +), and Python reduces each one to a single value.{{cite:3}} Working out the answer is called evaluating the expression.

OperatorDoesExampleShows
+Addprint(7 + 2)9
-Subtractprint(7 - 2)5
*Multiply (a star, not the letter x)print(7 * 2)14
/Divideprint(10 / 2)5.0

Division with / always gives a number with a decimal point, so 10 / 2 shows 5.0, not 5.{{cite:4}} And Python follows the usual maths order: * and / happen before + and -. So 2 + 3 * 4 is 14. Put parentheses around the part you want done first: (2 + 3) * 4 is 20.

Try it: minutes in a week

A week has 7 days, a day has 24 hours, and an hour has 60 minutes. Print how many minutes there are in a week. Let Python do the multiplying: your line should use *, not a number you worked out yourself.

Stuck? A hint

You can multiply more than two numbers in one expression: 2 * 3 * 4 is fine. Leave out the quotes, or Python will show your calculation as text instead of the answer.

Errors are normal

Sooner or later you'll type something Python can't understand. When that happens it stops and shows an error message. Nothing is broken. As Automate the Boring Stuff puts it, "error messages don't damage your computer, though, so don't be afraid to make mistakes."{{cite:3}} The same book points out that even people with decades of programming experience run into them constantly.{{cite:3}}

Here is the message for a line that is missing its closing quote:

oops.py
print("Hello)
Shows File "oops.py", line 1 print("Hello) ^ SyntaxError: unterminated string literal (detected at line 1)

Read error messages from the bottom up:

  1. The last line names the problem. SyntaxError means Python couldn't make sense of how the line is written. "Unterminated string literal" means a string was never closed: its ending quote is missing. (A string literal is just a string typed straight into your code.)
  2. The line above points to the spot. The ^ marks where Python got confused.
  3. line 1 says which line to look at. In longer programs this saves a lot of searching.

Python also cares about capital letters. print and Print are different words to it, and only one of them exists. Writing Print("hi") gives NameError: name 'Print' is not defined. Did you mean: 'print'? A name is a word Python looks up, like print. "Not defined" means Python has never heard of that word, so it can't do anything with it. Python even suggests the fix.

Try it: fix three mistakes

This program should show Good morning, then Python is fun, then 7. It has one mistake on each line. Press Run, read the last line of the error, fix that mistake, and run again until it works.

Watch what prints as you go. While any line has a SyntaxError, nothing prints at all, because Python checks how the whole file is written before running any of it. A NameError is different: Python only finds it when it reaches that line, so the lines above it still print.

Stuck? A hint

Fix one error at a time. Line 1 is missing something at the end of its text. Line 2 has a capital letter where it shouldn't. Line 3 opens something it never closes.
