Tuples and sets

Two more ways to group values. Tuples are fixed little bundles, handy for returning several answers at once. Sets are bags of unique items that answer "have I seen this before?" instantly, a check that many interview problems need.

Tuples: a fixed bundle

In real life

A map location is two numbers that belong together: latitude and longitude. You'd never change just one of them on its own; together they mean one place. A date of birth (day, month, year) is the same.

A tuple is like a list written with round brackets instead of square ones, with one big difference: it can't be changed after it's made. It's immutable, like a string.13

place.py
lagos = (6.52, 3.38)
print(lagos[0])
lat, lon = lagos          # unpack into two variables
print(f"Latitude {lat}, longitude {lon}")
Shows6.52 Latitude 6.52, longitude 3.38

The line lat, lon = lagos is unpacking: one name per item, filled in order.1 You already did this with for item, price in prices.items() in Lesson 13.

Two tuple tricks you'll use constantly

Swapping. a, b = b, a swaps two variables in one line, no temporary variable needed.2

Returning several values. A function can return smallest, largest. That returns one tuple, which the caller can unpack: low, high = min_max(numbers).

New words

Tuple
A fixed, unchangeable sequence: (6.52, 3.38).
Unpacking
Giving each item of a sequence its own name: lat, lon = lagos.

Try it: smallest and largest at once

Write min_max(numbers) that returns a tuple of the smallest and largest numbers, in that order. You may use min() and max().

Sets: each thing once

In real life

A sticker album: you either have a sticker or you don't. Getting the same sticker twice doesn't give you two places in the album. And checking whether you have one is instant: you go straight to its spot.

A set holds unique items with no duplicates and no particular order. It's written with curly braces, but without the colons a dictionary has. It answers "is this in here?" very fast, even for huge sets.4

stickers.py
album = {"lion", "eagle"}
album.add("shark")
album.add("lion")           # already there: no change
print(len(album))
print("eagle" in album)
print(set([3, 1, 3, 2, 1]))  # duplicates disappear
Shows3 True {1, 2, 3}

Careful: {} on its own makes an empty dictionary. An empty set is written set().4

Comparing two sets

Sets can be combined like circles in a diagram:4

  • a & b (intersection): items in both.
  • a | b (union): items in either.
  • a - b (difference): items in a but not in b.

New words

Set
An unordered collection of unique items: {"lion", "eagle"}.
Intersection, union, difference
In both, in either, in the first but not the second.

Try it: friends in common

Write in_common(friends_a, friends_b) that takes two lists of names and returns a sorted list of the names that appear in both. Use sets, then sorted() to turn the result into an ordered list.

The "seen before?" pattern

In real life

A doorman with a guest list who ticks off names as people arrive. If someone gives a name that's already ticked, he knows straight away that name was used twice, without re-reading the whole list.

To find a repeat while going through a list, keep a set of everything you've seen so far. For each new item, check the set first, then add it. Because checking a set is fast, this is much quicker on big lists than comparing every item with every other item. That speed difference is exactly what Lesson 19 (Big O) is about, and this pattern solves LeetCode 217 in Lesson 20.

Try it: first repeated item

Write first_repeat(items) that returns the first item that appears for a second time while reading left to right, or None if nothing repeats. In ["a", "b", "c", "b", "a"], it's "b": the second b comes before the second a.

Stuck? A hint

For each item: if it's already in seen, return it straight away. Otherwise seen.add(item) and keep going.

Check yourself

1. After a, b = 1, 2 and a, b = b, a, what is a?

The right side is worked out first as (2, 1), then unpacked into a and b, swapping them.

2. What is len(set("banana"))?

The unique letters are b, a and n.

3. What does {} create?

Empty curly braces are a dictionary. An empty set is set().

4. What is {1, 2, 3} - {2, 3, 4}?

Difference keeps what's in the first set but not in the second.
