Sliding window

Many problems ask about a stretch of neighbouring items: the best run of days, the longest piece of text without repeats. Instead of re-checking every stretch from scratch, you slide a window along and update it as it moves.

Remember the best so far

In real life

Looking back over a month of a share's price, you want the biggest profit from buying on one day and selling on a later day. You don't need to compare every pair of days. Walk forward day by day remembering one thing: the cheapest price so far. Each day, ask "if I'd bought at that cheapest point and sold today, what would I make?"

That's LeetCode 121.3 Comparing every buy day with every later sell day is O(n²). Keeping the lowest price seen so far makes it one pass, O(n), with O(1) extra space. It's the simplest version of this lesson's idea: as you move along, keep a small summary of what's behind you instead of looking back.

LeetCode 121: Best Time to Buy and Sell Stock

prices[i] is the price on day i. Return the most profit from one buy followed by one later sell, or 0 if no profit is possible.

Stuck? A hint

For each price: first update lowest if today is cheaper. Then work out today's profit, price - lowest, and keep it if it beats best.

A window of fixed size

In real life

A train window shows exactly four fields at a time. As the train moves, one new field appears on the right and one disappears on the left. To keep a running total of cows in view, you don't recount everything: add the cows in the new field, subtract the cows in the one that left.

A contiguous stretch of a list (items next to each other, no gaps) is called a subarray; in a string it's a substring. A sliding window is a subarray you move along one step at a time.1 For a window of size k, summing each window from scratch costs O(n·k). Sliding costs O(n): add the item entering on the right, subtract the item leaving on the left.

slide.txt
nums = [1, 12, -5, -6, 50, 3], k = 4
first window  [1, 12, -5, -6]        sum 2
slide: +50 -1  [12, -5, -6, 50]       sum 51
slide: +3 -12  [-5, -6, 50, 3]        sum 42

LeetCode 643: Maximum Average Subarray I

Return the largest average of any k neighbouring numbers in nums.4 Find the largest window sum by sliding, then divide by k once at the end.

Stuck? A hint

Loop for i in range(k, len(nums)):. The item entering is nums[i]; the one leaving is nums[i - k]. Update window, then best = max(best, window).

A window that grows and shrinks

In real life

A caterpillar crawling along a leaf: its head stretches forward, and when it gets uncomfortable, its tail catches up. It's never longer than it can comfortably be, and it never goes backwards.

LeetCode 3 asks for the longest substring with no repeated characters.5 Keep a window from left to the current position right, and a set of the characters inside it. Move right forward one character at a time. If the new character is already in the window, shrink from the left (removing characters from the set) until it isn't. Then add it and check the length.

Each character is added once and removed at most once, so even with the inner while loop, the total work is O(n).2

caterpillar.txt
s = "abcabcbb"
right=0 'a'  window "a"      best 1
right=1 'b'  window "ab"     best 2
right=2 'c'  window "abc"    best 3
right=3 'a'  'a' is inside: drop 'a' from the left -> "bca"
right=4 'b'  'b' is inside: drop 'b' -> "cab"
...          best stays 3

LeetCode 3: Longest Substring Without Repeating Characters

Return the length of the longest substring of s with all different characters.

Hint 1: shrinking

while s[right] in window: remove s[left] from the set and move left forward. Sets have .remove(), the opposite of .add().

Hint 2: the window's length

After adding s[right], the window runs from left to right inclusive, so its length is right - left + 1.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. A window of size k slides one step right. How do you update its sum?

Only two items change, so updating is O(1) per step instead of O(k).

2. In Best Time to Buy and Sell Stock, what do you track as you go?

The best sale today always uses the cheapest earlier buy.

3. Why is LeetCode 3 O(n) even with a while loop inside the for loop?

left only moves forward, so across the whole run the inner loop does at most n removals in total.

4. Which of these is a contiguous subarray of [3, 1, 4, 1, 5]?

Contiguous means neighbouring items in their original order, with no gaps.
