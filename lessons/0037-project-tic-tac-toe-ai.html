A board and a referee

In real life

Before any clever play, a game needs a board and a referee who can say "that square's taken" and "X wins".

This project follows Robert Heaton's two-part brief from the Project Based Learning list.123 The board is a 3 by 3 grid (Lesson 16) holding "X", "O", or None for an empty square.

Milestone 1: who has won?

Write get_winner(board) returning "X" or "O" if that player has three in a row (any row, column or diagonal), otherwise None.1

Stuck? A hint

A row is board[i]; a column is [board[0][i], board[1][i], board[2][i]]; the diagonals use positions (0,0),(1,1),(2,2) and (0,2),(1,1),(2,0). A line wins if its first value isn't None and all three are equal: a == b == c works in Python.

Milestone 2: legal moves

Write legal_moves(board) returning a list of (row, col) tuples for every empty square, in reading order (top row first, left to right).

Minimax: imagine every future

In real life

A careful chess player thinks: "If I move here, what's my opponent's best reply? And then my best answer to that?" They assume the opponent always plays as well as possible, and choose the move whose worst outcome is the best. With noughts and crosses, the game is small enough to imagine every possible future.

Minimax gives each position a score from the AI's point of view: +10 if the AI has won, -10 if it has lost, 0 for a draw.2 For a position that isn't finished, try every legal move, score the position each one leads to (recursively, Lesson 25), and then:

  • on the AI's turn, take the highest score (it picks its best move);
  • on the opponent's turn, take the lowest (assume they play their best too).

Trying a move means: place it, recurse, then remove it again. That's exactly the choose / explore / un-choose of backtracking (Lesson 32). The tree of all possible games is called the game tree.

shape.txt
minimax(board, player to move, ai):
    if someone has won:      return +10 if it's ai, else -10
    if no moves are left:    return 0
    for each legal move:
        place it
        score = minimax(board, the other player, ai)
        remove it
    return the biggest score if player is ai, else the smallest

Milestone 3: minimax and best_move

Finish minimax(board, player, ai) and best_move(board, ai). best_move tries each legal move for the AI, scores it with minimax (the opponent moves next), and returns the move with the highest score. get_winner and legal_moves are already written for you.

def ask_move(board):
    while True:
        text = input("Your move as row col (like 1 2): ").split()
        if len(text) == 2 and text[0].isdigit() and text[1].isdigit():
            r, c = int(text[0]), int(text[1])
            if 0 <= r < 3 and 0 <= c < 3 and board[r][c] is None:
                return r, c
        print("That's not a free square. Try again.")


def play():
    board = [[None] * 3 for _ in range(3)]
    human, ai = "X", "O"
    turn = "X"
    while get_winner(board) is None and legal_moves(board):
        render(board)
        if turn == human:
            r, c = ask_move(board)
        else:
            r, c = best_move(board, ai)
            print(f"AI plays {r} {c}")
        board[r][c] = turn
        turn = other(turn)
    render(board)
    winner = get_winner(board)
    print(f"{winner} wins!" if winner else "It's a draw.")


if __name__ == "__main__":
    play()

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. On the opponent's turn, which score does minimax pick?

It assumes the opponent plays their best, which is the worst for the AI.

2. Why remove each trial mark after scoring it?

Place, recurse, undo: the backtracking pattern from Lesson 32.

3. What does minimax return for a finished game the AI lost?

Scores are from the AI's point of view: a loss is -10.

4. What does None or "." evaluate to?

or gives the first value that counts as true; None counts as false, so it gives ".".
