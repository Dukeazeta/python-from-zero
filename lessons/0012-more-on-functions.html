What happens in a function stays in the function

In real life

A meeting room whiteboard: during the meeting you scribble working notes on it. When the meeting ends, the board is wiped. Anything you want to keep, you have to take out of the room with you, written down.

Variables created inside a function, including its parameters, are local: they exist only while the function runs, and they're wiped when it returns.1 Variables made outside any function are global. A function's local score is a completely separate jar from a global score, even with the same label.

whiteboard.py
def add_bonus(score):
    score = score + 10   # changes the local score only

score = 50
add_bonus(score)
print(score)
Shows50

The function added 10 to its own whiteboard copy, then the board was wiped. The way to get a result out is the one you learned last lesson: return it, and store what comes back: score = add_bonus(score).

Because of this, a function can't change your other variables by accident, so you can understand each function on its own: values come in through parameters and go out through return.

Change the program so it prints 60: make add_bonus return the new score, and store the result.

Default values and returning early

In real life

Ordering tea: "With milk, unless I say otherwise." Most of the time you don't have to say anything, but you can change it when you want. And when you search a bag for your phone, you stop the moment you find it.

A parameter can have a default value, used when the caller doesn't pass one:2

tea.py
def order_tea(milk="yes"):
    return f"Tea, milk: {milk}"

print(order_tea())
print(order_tea("no"))
ShowsTea, milk: yes Tea, milk: no

return also ends the function immediately, even in the middle of a loop. That makes "search and stop" short to write: return as soon as you find it, and put a final return after the loop for the "not found" case.

find.py
def has_negative(numbers):
    """Return True if any number in the list is below zero."""
    for n in numbers:
        if n < 0:
            return True      # found one: stop now
    return False             # checked them all: none found

The string on the function's first line is a docstring: a short description of what the function does, for whoever reads it next (including you, later).3

New words

Local variable
A variable made inside a function. It disappears when the function returns.
Global variable
A variable made outside every function.
Default value
A value a parameter uses when no argument is given: milk="yes".
Docstring
A string on a function's first line describing what it does.

Big problems, small functions

In real life

A restaurant kitchen doesn't have one cook doing everything. One person chops, one handles the grill, one plates up. Each job is simple on its own, and the head chef just calls on each of them.

When a problem feels big, split it into small functions that each do one job, then combine them. A small function used by a bigger one is often called a helper. Breaking a problem down like this is called decomposition. Most algorithm problems get much easier once you break them down like this.

Variables made inside a function are local and are wiped when it returns. Use return to get values out.

No second argument was passed, so n uses its default value, 2.
