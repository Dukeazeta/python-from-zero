Why dictionaries are so fast

In real life

A cloakroom: you hand over your coat and get ticket number 47. When you come back, the attendant doesn't search every hook; they walk straight to hook 47. The ticket number tells them exactly where to look.

Python's dict and set are built on a hash table. When you store a key, Python runs it through a hash function that turns it into a number, and that number says which slot to put it in. Looking it up later repeats the calculation and goes straight to the slot, instead of searching.1 That's why key in my_dict is O(1) on average (Lesson 19).

In LeetCode problems, a Python list is usually called an array. The pattern for this lesson:

The hash map pattern. If the slow answer is "for each item, search the rest of the list", walk the list once instead, and keep a set or dictionary of what you've seen so the search becomes an O(1) lookup. You spend O(n) memory to save a whole factor of n in time.

LeetCode 217: Contains Duplicate

Return True if any value appears at least twice in nums, and False if every value is different.4 You did this in Lesson 19; write it again from memory in LeetCode's format.

A one-line version

Once yours passes: return len(set(nums)) != len(nums) also works. A set drops duplicates, so if it's shorter than the list, something repeated. Same O(n), but it can't stop early.

Counting characters

In real life

Two bags of Scrabble tiles spell different words, "listen" and "silent". Are they the same tiles? Tip each bag out and count: three E's? two N's? If every letter count matches, the bags are interchangeable.

An anagram uses exactly the same letters in a different order. Sorting both words and comparing works, but sorting is O(n log n). Counting each word's letters into a dictionary (Lesson 13) and comparing the dictionaries is O(n).2

Two Sum

In real life

You're at a party and need a partner whose age adds to yours to make exactly 50. You're 20, so you need someone who's 30. Instead of asking everyone their age again and again, there's a register at the door listing everyone who's arrived and their age. You just check: "is anyone 30 on the list?"

Given a list of numbers and a target, find the positions of the two numbers that add up to it. The slow way tries every pair: O(n²). The hash map way walks the list once. For each number, the partner you need is target - number, called the complement. Check whether the complement is already in a dictionary of numbers you've seen (mapping number to index). If it is, you're done. If not, add the current number and carry on.6

trace.txt
nums = [2, 7, 11, 15], target = 9
i=0  num=2   need 7   seen={}          not there, store 2 -> 0
i=1  num=7   need 2   seen={2: 0}      found at 0! answer [0, 1]

LeetCode 1: Two Sum

Return a list of the two indexes, smaller first. Each input has exactly one answer, and you can't use the same item twice.

Hint 1: you need the index too

Loop with for i in range(len(nums)): and num = nums[i]. Python also has for i, num in enumerate(nums):, which hands you both at once; that's the tidy way.

Hint 2: order of the two steps

Check for the complement before storing the current number. Otherwise [3, 3] with target 6 could match a number with itself.

Challenge: a clever key

In real life

Sorting post into pigeonholes: each letter goes into the hole labelled with its postcode. Letters with the same postcode end up together without you ever comparing two letters directly.

To group anagrams, you need a label that's the same for every word in a group. Sorting a word's letters gives exactly that: "eat", "tea" and "ate" all become "aet". Use that as a dictionary key and put each word in the list for its key. "".join(sorted(word)) turns the sorted letters back into a string.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. What's the Big O of the hash map Two Sum?

One pass with O(1) lookups is O(n) time; the dictionary can hold up to n numbers.

2. In Two Sum with target 10, you're at the number 4. What do you look up?

The complement is target minus the current number: 10 - 4.

3. Why are "listen" and "silent" given the same key in Group Anagrams?

Sorting the letters gives the same string for every anagram.

4. When is the hash map pattern a good idea?

A search inside a loop is O(n²); a set or dict lookup turns it into O(n), using extra memory.
