A loop inside a loop

In real life

A clock: for every one step of the hour hand, the minute hand goes all the way round. Or an usher checking tickets: for each row of the cinema, go along every seat in that row, then move to the next row.

Put a loop inside another loop's block and you get a nested loop. The inner loop runs completely, from start to finish, for every single step of the outer loop:

seats.py
for row in ["A", "B"]:
    for seat in range(1, 4):
        print(f"{row}{seat}", end=" ")
    print()          # finish the row's line
ShowsA1 A2 A3 B1 B2 B3

Two small new things: print(..., end=" ") ends with a space instead of a new line, so the seats stay on one line, and an empty print() just starts a new line.

How many times does the inner block run? Outer count times inner count: 2 rows times 3 seats is 6. Keep that multiplication in mind; it becomes important when we talk about speed in Lesson 19.

Grids as lists of lists

In real life

A spreadsheet: you find a cell by its row and then its column. "Row 2, column 3." A noughts-and-crosses board is a 3 by 3 grid of the same kind.

A grid is stored as a list whose items are themselves lists: one inner list per row.2 Two indexes find a cell: first the row, then the column.

board.py
board = [
    ["X", "O", "X"],
    [" ", "X", "O"],
    ["O", " ", "X"],
]
print(board[0][2])          # row 0, column 2
print(len(board))            # number of rows
print(len(board[0]))         # number of columns
for row in board:
    print(" | ".join(row))
ShowsX 3 3 X | O | X | X | O O | | X

To visit every cell with its position, loop over the row numbers and, inside, the column numbers: for r in range(len(board)): and for c in range(len(board[0])):, then use board[r][c].

Building lists the short way

A list comprehension builds a list in one line: [n * n for n in range(5)] gives [0, 1, 4, 9, 16]. Read it as "n times n, for each n in range(5)".1 It's the same as an empty list plus a for loop with append, just shorter.

For grids, it's the safe way to make one: [[0] * 3 for _ in range(2)] makes 2 rows of 3 zeros. (_ is a name programmers use for a loop variable they don't need.)

The shared-row trap

The tempting shortcut [[0] * 3] * 2 looks the same but isn't: it makes one row and puts it in the grid twice. Change a cell in one row and the "other" row changes too, because they're the same list.3 Always build grids with a comprehension or a loop.

Try it: a times-table grid

Write times_grid(n) that returns an n by n grid where the cell at row r, column c holds (r + 1) * (c + 1). times_grid(3) returns [[1, 2, 3], [2, 4, 6], [3, 6, 9]].

Stuck? A hint

Outer loop over r: start an empty row. Inner loop over c: append the product to row. After the inner loop, append row to grid.

Try it: flip a grid

Write transpose(grid) that returns a new grid whose rows are the original's columns (LeetCode 867). [[1, 2, 3], [4, 5, 6]] becomes [[1, 4], [2, 5], [3, 6]].

Stuck? A hint

The new grid has one row for each column of the old one. So the outer loop goes over column numbers, and the inner loop collects grid[r][c] for every row r.

Counting a cell's neighbours

In real life

Standing on one square of a chessboard, the squares touching yours are up, down, left, right and the four diagonals: up to 8. But if you're on the edge, some of those squares don't exist: you'd be stepping off the board.

Many grid problems, including Conway's Game of Life (your project in Lesson 364), need the cells around a given cell. The neat way is to loop over the row offsets -1, 0, 1 and column offsets -1, 0, 1, skip the (0, 0) offset (that's the cell itself), and skip any position that falls off the grid. That last check is called bounds checking:

bounds.py
def in_bounds(grid, r, c):
    return 0 <= r < len(grid) and 0 <= c < len(grid[0])

Without it, row -1 would wrap round to the last row (negative indexes count from the end), and there's no error message to warn you.

New words

Nested loop
A loop inside another loop's block.
Grid
A list of lists, one inner list per row: grid[row][col].
List comprehension
A one-line list builder: [x * 2 for x in nums].
Bounds checking
Making sure a position is inside the grid before using it.
Transpose
Swap a grid's rows and columns.

Try it: live neighbours

Write live_neighbours(grid, r, c) that returns how many of the up-to-8 cells around (r, c) hold 1. Don't count the cell itself, and don't step off the edge.

Stuck? A hint

Inside the inner loop: skip when both offsets are 0 (continue). Work out nr = r + dr and nc = c + dc. If they're in bounds, add grid[nr][nc] to count (it's 1 or 0).

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. An outer loop runs 4 times and an inner loop 5 times. How many times does the inner block run?

The inner loop runs fully for every outer step: 4 times 5.

2. With g = [[1, 2], [3, 4], [5, 6]], what is g[2][0]?

Row 2 is [5, 6], and column 0 of that row is 5.

3. What does [n + 1 for n in [1, 2, 3]] give?

It takes each n and puts n + 1 in the new list.

4. Why is [[0] * 3] * 3 a bad way to make a grid?

The outer * 3 repeats a reference to one row, so changing one row changes them all.
