Dictionaries: looking things up by name

Lists find things by position. Dictionaries find things by name: a person's phone number, a word's meaning, how many times a letter appears. Many fast solutions to interview problems use them.

Find it by name, not by position

In real life

Your phone's contacts. You never think "Mum is contact number 37". You search for "Mum" and get her number. The name is how you look things up; the number is what you find.

A dictionary stores pairs: a key (the name you look up) and its value (what you find). It's written in curly braces, with a colon between each key and its value.14

contacts.py
phone = {"Mum": "0803 111 2222", "Ada": "0812 333 4444"}
print(phone["Ada"])
phone["Bo"] = "0905 555 6666"     # add a new pair
phone["Mum"] = "0803 999 0000"    # change an existing one
print(len(phone))
Shows0812 333 4444 3

Reading and writing use square brackets like lists, but with the key instead of a position. Writing to a key that doesn't exist yet adds it; writing to one that does replaces its value. Keys are unique: one value per key.

Missing keys

Look up a key that isn't there and you get a KeyError: phone["Zara"] gives KeyError: 'Zara'.1 Two safe ways to ask:

  • "Zara" in phone is True or False (it checks the keys).2
  • phone.get("Zara", "unknown") gives the value if the key exists, otherwise the fallback, "unknown".3

Going through a dictionary

In real life

Reading down a price list in a shop window: item, price; item, price. You can read just the item names, just the prices, or both together, line by line.

Three methods give you the parts of a dictionary:2 .keys(), .values(), and .items(), which gives each key and value together. With items(), the for line can unpack both into two names:

prices.py
prices = {"bread": 1200, "milk": 900, "eggs": 2500}
for item, price in prices.items():
    print(f"{item}: {price}")
print(sum(prices.values()))
Showsbread: 1200 milk: 900 eggs: 2500 4600

A plain for key in prices: loops over the keys. Dictionaries keep the order you added things in.

Counting with a dictionary

In real life

Counting votes on a whiteboard: each time a name is called out, you find it on the board and add a tally mark. If the name isn't on the board yet, you write it with one mark.

That's the frequency count. You'll use it in several LeetCode problems in Lesson 20:

votes.py
votes = ["Ada", "Bo", "Ada", "Chi", "Ada", "Bo"]
tally = {}
for name in votes:
    if name in tally:
        tally[name] += 1
    else:
        tally[name] = 1
print(tally)
Shows{'Ada': 3, 'Bo': 2, 'Chi': 1}

The if / else can be shortened with get: tally[name] = tally.get(name, 0) + 1 means "the current count, or 0 if there isn't one, plus 1".

Frequency count
A dictionary from each item to how many times it appears.

Stuck? A hint
