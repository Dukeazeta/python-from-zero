The terminal: texting your computer

In real life

Most of the time you use a computer by clicking and tapping. There is another way: you type a short message, press Enter, and the computer types a reply. It's like texting someone who follows instructions perfectly, but only if you spell them exactly right.

The window where you have that text conversation is called the terminal. Each message you type is a command.1 The steps below change a little depending on your computer, so check it's picked the right one:

  1. Open the terminal. Press the Windows key, type Terminal, and press Enter. Press Cmd + Space, type Terminal, and press Enter. Press Ctrl + Alt + T, or find Terminal in your apps. A window opens with a line that ends in >%$, something like this:

    Terminal
    PS C:\Users\you>~ %~ $

    That line is the prompt: the computer saying "your turn". It also shows the folder you're in right now (yours will show your own name~ means your home folder).

  2. Ask which Python you have. Type this and press Enter:

    Terminal
    PS C:\Users\you> python --version~ % python3 --version~ $ python3 --version
    Shows something likePython 3.12.10

    Paste what your terminal showed:

    Python is installed and the terminal can find it. Any version starting with 3 is fine for this course.

    If it says 'python' is not recognized, or the Microsoft Store opens, Python isn't set up yet. Install it from python.org and tick Add python.exe to PATH in the installer, then open a new terminal. If it says command not found, or a box offers to install developer tools, install Python from python.org, then open a new terminal. If it says command not found, install Python 3 with your system's package manager (on Ubuntu: sudo apt install python3). Stuck? Ask in the chat and we'll fix it together.

The shell: a live chat with Python

In real life

Think of a phone call. You say one thing, you get an answer straight away, and when you hang up nothing is written down. That's fine for quick questions, but nothing is kept.

Python has the same thing, called the interactive shell. You type one line, Python answers immediately. When Python is waiting for you, it shows three arrows, >>>. This is called the Python prompt.2

  1. Start the shell. In the terminal, type pythonpython3 and press Enter. A few lines of information appear, then >>>.

  2. Ask it something. Type each line below and press Enter after each one:

    Python shell
    >>> 2 + 2
4
>>> 7 * 24 * 60
10080
>>> "Hello"
'Hello'

    Notice: no print needed. The shell always shows the value of whatever you type, like a calculator showing the answer. It shows strings with quotes around them so you can tell text from numbers.

  3. Hang up. Type exit() and press Enter. The >>> disappears and you're back at the terminal's normal prompt. Everything you typed in the shell is gone.2

New words

Terminal
A window where you control the computer by typing commands.
Command
One typed instruction, sent by pressing Enter.
Prompt
The text that shows it's your turn to type: >%$ in the terminal, >>> in Python's shell.
Interactive shell
Python answering one line at a time. Nothing is saved.

Files: write it once, run it any time

In real life

If the shell is a phone call, a file is a written recipe. You write every step down, save it, and anyone can follow it again tomorrow, from the first step to the last, exactly the same way.

A Python program saved as a file is called a script. Python files have names ending in .py, like hello.py.3 You write it in a code editor, a program like a notes app made for code. We'll use VS Code.

Make a folder for your course work

In real life

The terminal is always "standing" inside one folder, like you standing in one room of a house. Commands act on the room you're in, so first you walk to the right room.

The command cd (short for "change directory"; directory is another word for folder) moves you into a folder.

  1. Make a course folder on your Desktop and walk into it. mkdir means "make directory". You only make it once; after that, the cd lines are all you need.

    Terminal
    PS C:\Users\you> cd Desktop~ % cd Desktop~ $ cd Desktop
...Desktop> mkdir python-courseDesktop % mkdir -p python-courseDesktop $ mkdir -p python-course
...Desktop> cd python-courseDesktop % cd python-courseDesktop $ cd python-course

    The prompt now shows python-course. That's how you know you're in the right room. (No Desktop folder? Leave out the first line, and the course folder goes in your home folder instead.)

  2. Make a folder for your practice code, inside the course folder:

    Terminal
    ...python-course> mkdir practicepython-course % mkdir -p practicepython-course $ mkdir -p practice

  3. Open a new file in VS Code.

    Terminal
    ...python-course> code practice\hello.pypython-course % code practice/hello.pypython-course $ code practice/hello.py

    VS Code opens with an empty tab called hello.py. (No VS Code? notepad practice\hello.py works too; say yes when it asks to create the file.) If the terminal says command not found: code, open VS Code, press Cmd + Shift + P, run Shell Command: Install 'code' command in PATH, then open a new terminal. (No VS Code? nano practice/hello.py opens a simple editor in the terminal: save with Ctrl + O then Enter, and leave with Ctrl + X.) (No VS Code? nano practice/hello.py opens a simple editor in the terminal: save with Ctrl + O then Enter, and leave with Ctrl + X.)

  4. Type your program, by hand, then save with CtrlCmdCtrl + S:

    hello.py
    # My first program file
print("Hello from my own computer!")
print("Minutes in a week:")
print(7 * 24 * 60)

    In a file you do need print. A recipe only does what's written in it: without print, Python would work out 7 * 24 * 60 and then throw the answer away without showing it.

  5. Run it. Back in the terminal:

    Terminal
    ...python-course> python practice\hello.pypython-course % python3 practice/hello.pypython-course $ python3 practice/hello.py
    ShowsHello from my own computer! Minutes in a week: 10080

    Paste the three lines your program printed:

    That's your first Python program, saved on your own computer and run from the terminal.

    Check that you saved the file (CtrlCmdCtrl + S) and that each line in hello.py matches the example, including capitals and punctuation.

The everyday loop: edit, save, run

Change hello.py so it also prints your name on a new line at the end. Save, then run the same command again. You can press the Up arrow key in the terminal to bring back the last command instead of typing it.

The most common beginner surprise: you edit the file, run it, and nothing changed. Almost always the file wasn't saved. In VS Code, an unsaved tab shows a round dot next to its name where the close button usually is.

When the terminal can't find your file

If you're in the wrong folder, Python can't find the file and says so:

Terminal
PS C:\Users\you> python practice\hello.py~ % python3 practice/hello.py~ $ python3 practice/hello.py
Shows... can't open file 'C:\\Users\\you\\practice\\hello.py'... can't open file '/Users/you/practice/hello.py'... can't open file '/home/you/practice/hello.py': [Errno 2] No such file or directory

Read the end first, as always: "No such file or directory". Python looked in the room you're standing in and the file wasn't there. Fix it with cd Desktop\python-coursecd Desktop/python-course, then run again.

An app for writing code, such as VS Code.

Another word for a folder.
cd

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. You see >>> on the screen. What does it mean?

Three arrows is Python's prompt: the interactive shell is ready for your next line.

2. You want to keep your code and run it again next week. Where do you write it?

The shell forgets everything when you exit. A file stays saved, like a written recipe.

3. You changed hello.py, ran it, and the old output appeared. Most likely cause?

Python runs what's saved on disk. Press Ctrl + S, then run again.

4. In a .py file, what does the line 7 * 6 show when you run it?

Python works it out, but only print shows things when running a file. The shell is the one that shows values on its own.
