Stacks: last in, first out

A stack only lets you touch the item on top. That's all you need for matching brackets, undo buttons and evaluating maths. Every function call your programs make uses one too.

Only the top plate

In real life

A stack of plates in a canteen. You put clean plates on top, and you take plates from the top. The plate washed last is the first one used. Getting the bottom plate means lifting off every plate above it.

A stack is a collection where you only add and remove at one end, the top. Adding is called push, removing is pop, and looking at the top without removing it is peek. The last item pushed is the first popped: LIFO, last in, first out.1

A Python list is already a good stack: append() pushes onto the end, pop() removes and returns the last item, and stack[-1] peeks.4 All three are O(1). Popping an empty list raises IndexError: pop from empty list, so check first: an empty list counts as false, so if stack: means "if there's anything on it".

undo.py
history = []
history.append("type hello")
history.append("make bold")
history.append("delete line")
print(history.pop())      # undo the last action
print(history[-1])        # what would be undone next
Showsdelete line make bold

Matching brackets

In real life

Russian dolls: each doll you open must be closed before the doll around it. You can't close the big doll while a small one inside is still open. The most recently opened doll is always the next one to close: a stack.

In "([{}])", every closing bracket must match the most recent unmatched opening one. Push each opening bracket. When a closing bracket arrives, the top of the stack must be its partner: pop it. If the stack is empty or the top doesn't match, the string is invalid. At the end, the stack must be empty: any leftovers were never closed.2

A dictionary from each closing bracket to its opener keeps the code short: pairs = {")": "(", "]": "[", "}": "{"}.

LeetCode 20: Valid Parentheses

Return True if every bracket in s is closed by the right kind, in the right order.5

Stuck? A hint

For each character: if it's a closing bracket (ch in pairs), the stack must be non-empty and its top must equal pairs[ch]; then pop. Otherwise push it. At the end, return len(stack) == 0.

A stack that knows its minimum

LeetCode 155 wants a stack class whose getMin() is O(1), with no searching.6 The trick: keep a second stack alongside. Every time you push a value, also push "the smallest value so far" onto the second stack. Pop both together. The second stack's top is always the current minimum.

A second structure that exists only to help the main one is often called an auxiliary stack.

LeetCode 155: Min Stack

Challenge: maths without brackets

In real life

Old pocket calculators worked like this: type the two numbers first, then the operation. "3, 4, plus" gives 7. Numbers wait on a pile until an operation comes along and combines the top two.

In Reverse Polish Notation (postfix), the operator comes after its two numbers: ["2", "1", "+", "3", "*"] means (2 + 1) × 3 = 9. No brackets are ever needed. Evaluate it with a stack: push numbers; on an operator, pop two, combine, push the result.3

Watch the order: the first number popped is the right-hand one. For "10", "2", "-" you pop 2, then 10, and compute 10 - 2. LeetCode also wants division that cuts off the decimal towards zero: int(a / b) does that (6 / -4 gives -1, not -2).7

LeetCode 150: Evaluate Reverse Polish Notation

tokens is a list of strings: numbers and the operators + - * /. Return the result as an int.

Careful with negative numbers

"-11" is a number, not an operator. Checking t in "+-*/" is safe because "-11" in "+-*/" is False: the whole string has to appear inside.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. Push 1, push 2, push 3, then pop. What comes off?

Last in, first out: the most recent push is on top.

2. Checking brackets, you reach ) and the top of the stack is [. Then?

The most recent opener must match. A [ closed by ) is invalid.

3. What does ["3", "4", "+", "2", "*"] evaluate to?

3 + 4 = 7, then 7 × 2 = 14.

4. Why does Min Stack keep a second stack?

The second stack remembers the minimum at every height, so it's still right after the smallest is popped.
