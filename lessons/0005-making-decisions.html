Questions with a yes or no answer

In real life

A light switch is either on or off. There's no "a bit on". Lots of everyday questions work the same way: Is it raining? Are you over 18? Is the shop open? The answer is yes or no.

Python has a type for yes-or-no answers, called Boolean (type bool). It has exactly two values: True and False, with capital letters and no quotes.1

You get Booleans by comparing values with comparison operators:2

OperatorAsksExampleGives
==equal to?5 == 5True
!=not equal to?"cat" != "dog"True
<less than?3 < 2False
>greater than?10 > 2True
<=less than or equal to?18 <= 18True
>=greater than or equal to?17 >= 18False

One equals sign or two?

This trips up everyone at first. One = stores a value (Lesson 3). Two, ==, asks whether two values are the same.2 A memory hook: two equals signs, two things being compared.

Comparisons care about type. "18" == 18 is False: one is text, the other a number. Another reason to convert input() answers with int().

New words

Boolean
The type with only two values, True and False.
Comparison operator
A symbol that compares two values and gives a Boolean, such as == or <.

if: do this only when it's true

In real life

A bouncer at a club door has one rule: "If you're 18 or over, come in. Otherwise, go home." Everyone gets checked, but what happens next depends on the answer.

An if statement runs some lines only when a condition (a question that gives True or False) is true. else gives the lines to run when it's false:4

bouncer.py
age = int(input("How old are you? "))
if age >= 18:
    print("Come in.")
else:
    print("Sorry, not tonight.")
print("Next, please!")
Shows (the person typed 16)How old are you? 16 Sorry, not tonight. Next, please!

Three things to notice:

  1. The colon. The if line and the else line both end with :. It means "here comes a block".
  2. The indentation. The lines that belong to the if are pushed in by 4 spaces. A group of lines indented together is called a block.3 The editor's Tab key adds 4 spaces for you.
  3. The last line isn't indented, so it's not part of either block. It runs every time.

Forget to indent and Python stops before running anything: IndentationError: expected an indented block after 'if' statement on line 2.

Try it: old enough to vote?

Ask Age? and convert the answer to a number. If the age is 18 or more, print You can vote. Otherwise print Not yet. Test it with 17, 18 and 30 in the Input box.

If 18 says "Not yet."

age > 18 means "more than 18", which leaves out 18 itself. Which operator means "18 or more"?

Try it: the secret word

Ask Password: . If the answer is exactly open sesame, print Welcome in. Otherwise print Wrong password.

Getting a SyntaxError on the if line?

Comparing needs two equals signs: if password == "open sesame":. One equals sign means "store", which isn't allowed there.

elif: more than two choices

In real life

A shop gives discounts: spend over 50,000 and get 20% off; otherwise over 20,000 gets 10% off; otherwise no discount. The cashier checks from the top and stops at the first rule that fits. Nobody gets two discounts.

elif (short for "else if") adds more checks between if and else.5 Python checks each condition from top to bottom and runs only the first block whose condition is true, then skips the rest.4

weather.py
temp = int(input("Temperature? "))
if temp >= 30:
    print("Hot. Drink water.")
elif temp >= 20:
    print("Warm. Nice day.")
else:
    print("Cool. Bring a jacket.")
Shows (the person typed 25)Temperature? 25 Warm. Nice day.

Because only the first true block runs, order matters. If you checked temp >= 20 first, 35 degrees would say "Warm", because 35 is also at least 20 and Python would stop there.

New words

Condition
An expression that gives True or False, used to decide what runs.
Block
A group of lines indented together under a line ending in :.
elif
An extra check between if and else. Only the first true one runs.

Try it: exam grades

Ask Score? and print the grade: 70 or more is A, 60 or more is B, 50 or more is C, anything lower is F. The starter code has the checks in the wrong order. Fix it.

Stuck? A hint

Try 85 in the starter code. It shows C, because 85 is at least 50 and that's the first check. Put the highest bar first.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. What does print(7 >= 7) show?

>= means "greater than or equal to", and 7 is equal to 7.

2. Which line checks whether name is Ada?

Comparing needs ==, and the if line must end with a colon.

3. With x = 15, which line prints? if x > 10: print A, elif x > 5: print B, else: print C

15 > 10 is true, so the first block runs and Python skips every elif and else after it.

4. How does Python know which lines belong to an if?

The colon starts a block, and the indented lines under it are the block.
