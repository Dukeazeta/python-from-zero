Lists: many values in one place

One variable holding one value only gets you so far. A list holds as many values as you like, in order. Lists are the first data structure you'll learn, and almost every algorithm problem starts with one.

A list keeps things in order

In real life

A train has carriages joined in a line. Each carriage has a number painted on it so you can find your seat. Odd thing about this train: the first carriage is numbered 0, not 1.

A list is a value that holds other values in order, written inside square brackets with commas between them. Each value in it is an item.1

train.py
foods = ["rice", "beans", "plantain", "yam"]
print(foods[0])
print(foods[2])
print(len(foods))
Showsrice plantain 4

The number in square brackets after a list is its index: which carriage you want. Indexes start at 0, so the first item is foods[0] and the fourth is foods[3].1 len() tells you how many items there are, just as it counts the characters in a string.

Counting from the back

A negative index counts from the end: foods[-1] is the last item ("yam") and foods[-2] the one before it.1 Handy when you don't know how long the list is.

Ask for a carriage that doesn't exist, like foods[4] on a four-item list, and you get IndexError: list index out of range. The last index is always one less than the length.

Changing a list

Lists can be changed after they're made. Put an index on the left of = to replace an item, and use .append() to add one to the end:3

shopping.py
shopping = ["milk", "eggs"]
shopping[0] = "oat milk"
shopping.append("bread")
print(shopping)
Shows['oat milk', 'eggs', 'bread']

The dot in shopping.append("bread") means "the list's own append tool". A function that belongs to a value like this is called a method. You'll meet lots of them.

New words

List
A value holding other values in order, written [a, b, c].
Item
One value inside a list.
Index
An item's position, starting from 0. -1 is the last item.
Method
A function that belongs to a value, used with a dot: shopping.append("bread").
IndexError
The error for an index past the end of a list.

Going through every item

In real life

Ticking off a shopping list in the supermarket: you look at each line in turn and do something with it. Same with checking whether something is on the list at all: you scan it from top to bottom.

A for loop works on lists exactly as it does on strings: the loop variable holds each item in turn.2 And in asks whether a value is anywhere in the list; not in asks the opposite.2

tick.py
shopping = ["milk", "eggs", "bread"]
for item in shopping:
    print("Got " + item)
if "eggs" in shopping:
    print("Remember: eggs are fragile")
ShowsGot milk Got eggs Got bread Remember: eggs are fragile

Quick answers about numbers

For a list of numbers, sum() adds them all, and min() and max() give the smallest and largest.5 The average is the sum divided by how many there are: sum(scores) / len(scores).

Try it: class average

Print the average of the scores, then the highest score, on separate lines. The average of this list is 75.0.

Doing it by hand

max() is great, but you need to know how it works inside: interviewers often ask you to find things in a list without the shortcut, and the same idea powers many algorithms. The trick: remember the biggest value seen so far, and update it whenever you see something bigger.

Taking part of a list

In real life

Cutting a slice of bread from a loaf: you say where the cut starts and where it ends, and you get that piece. The loaf itself stays whole.

A slice gives you a new list with part of the original: items[start:stop]. Like range, it starts at start and stops before stop.14 Leave out a number to go from the very start or to the very end.

With letters = ["a", "b", "c", "d", "e"]Gives
letters[1:3]['b', 'c']
letters[:2]['a', 'b'] (the first two)
letters[2:]['c', 'd', 'e'] (from index 2 to the end)
letters[-2:]['d', 'e'] (the last two)

New words

Slice
Part of a list, written items[start:stop]. Stops before stop.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. With colours = ["red", "green", "blue"], what is colours[1]?

Indexes start at 0, so index 1 is the second item.

2. A list has 5 items. What is the index of the last one?

Counting from 0, five items have indexes 0 to 4. -1 always means the last one.

3. What does [10, 20, 30, 40][1:3] give?

Start at index 1 (20) and stop before index 3.

4. Which line adds "tea" to the end of the list drinks?

append is a list method. drinks[-1] = "tea" would replace the last item instead of adding one.
