A table instead of a row

In real life

A city laid out in a grid of streets. You walk from the top-left corner to the bottom-right, only ever going right or down. How many different routes are there? To reach any corner, your last step came either from the corner above or the corner to the left.

That's LeetCode 62.4 The recurrence: paths[r][c] = paths[r - 1][c] + paths[r][c - 1]. Every cell in the top row and left column has exactly one route (straight along the edge). Fill the rest row by row, and the bottom-right cell is the answer: O(rows × columns).

grid.txt
3 rows by 4 columns:
1  1  1  1
1  2  3  4
1  3  6  10     <- 10 routes

Build the table with a list comprehension (Lesson 16), never with [[1] * n] * m, which repeats one shared row.

LeetCode 62: Unique Paths

Return the number of routes from top-left to bottom-right of an m by n grid, moving only right or down.

Fewest coins

In real life

A shopkeeper giving change wants to use as few coins as possible. Grabbing the biggest coin first usually works with real currencies, but not always: with coins of 1, 3 and 4, making 6 greedily gives 4 + 1 + 1 (three coins), while 3 + 3 uses two.

So try every coin, and remember answers. Let best[a] be the fewest coins that make amount a. For each amount, try each coin as the last one used: best[a] = min(best[a - coin] + 1) over all coins that fit.1 best[0] is 0. Amounts you can't make start as infinity, float("inf"), which is bigger than any number, so min ignores them.3 If best[amount] is still infinity at the end, return -1.5

LeetCode 322: Coin Change

Return the fewest coins needed to make amount (each coin can be used any number of times), or -1 if it's impossible.

Stuck? A hint

Two loops: amounts a from 1 to amount, and inside, each coin. If the coin fits (coin <= a), see whether best[a - coin] + 1 beats the current best[a].

Comparing two texts

In real life

Two people write down the same shopping list from memory. Some items match and appear in the same order, some are extra. The longest run of shared items in the same order shows how similar the lists are. Tools that show "what changed" between two versions of a file, like Git (Lesson 35), are built on this idea.

A subsequence keeps some characters in order, possibly with gaps: "ace" is a subsequence of "abcde". LeetCode 1143 asks for the length of the longest one shared by two strings.6

Make a table with a row for each prefix of text1 and a column for each prefix of text2 (plus an empty row and column of zeros). For each cell, compare the two current characters:

  • They match: 1 + the cell diagonally up-left (both strings one shorter).
  • They don't: the bigger of the cell above and the cell to the left (drop a character from one string or the other).

LeetCode 1143: Longest Common Subsequence

Return the length of the longest common subsequence of text1 and text2.

Stuck? A hint

Nested loops over i and j from 1. If text1[i - 1] == text2[j - 1], the cell is table[i - 1][j - 1] + 1; otherwise max(table[i - 1][j], table[i][j - 1]).

A recipe for any DP problem

  1. Define the state in words: "best[a] is the fewest coins to make a". Everything follows from this sentence.

  2. Find the recurrence by thinking about the last choice: last step, last coin, last characters.

  3. Set the base cases: the smallest states, answered directly (0 coins for amount 0, one route along the edge).

  4. Choose an order so that every cell's ingredients are filled in before the cell itself.

  5. Read off the answer, then check the Big O: usually the number of states times the work per state.

Check yourself

From memory, without scrolling up. A wrong answer here costs nothing: you just pick again.

1. In Unique Paths, each cell is filled from which cells?

You can only arrive by moving down (from above) or right (from the left).

2. Why does Coin Change start every amount at infinity?

Infinity means "impossible so far": any real count is smaller, and if it stays infinity the answer is -1.

3. Is "aec" a subsequence of "abcde"?

Gaps are allowed, but the characters must stay in the original order, and c comes before e.

4. What's the first step of the DP recipe?

A clear state definition is what makes the recurrence findable.
