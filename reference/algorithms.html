Algorithm patterns

The algorithms track (Lessons 19 to 34): costs, the pattern to reach for, and a template for each. Source: Problem Solving with Algorithms and Data Structures using Python and the Python TimeComplexity page.

Big O · L19

O(1)        dict/set lookup, append
O(log n)    binary search, heap push/pop
O(n)        one pass, x in list
O(n log n)  sorting
O(n²)       loop inside a loop
O(2ⁿ) O(n!) subsets, permutations

Drop constants and smaller terms. Nested loops multiply; loops in a row add.

Which pattern? A quick guide

Search inside a loop: hash map or set. Sorted list, pair or target: two pointers or binary search. Contiguous run: sliding window. Matching or undo: stack. Nearest first: BFS. Top k: heap. All combinations: backtracking. Repeated subproblems: DP.

Two pointers · L21

    total = a[left] + a[right]

Sliding window · L22

window, left, best = set(), 0, 0
for right in range(len(s)):
    while s[right] in window:
        window.remove(s[left])
        left += 1
    window.add(s[right])
    best = max(best, right - left + 1)

Binary search · L24

low, high = 0, len(a) - 1
while low <= high:
    mid = (low + high) // 2
    if a[mid] == target: return mid
    if a[mid] < target: low = mid + 1
    else: high = mid - 1
return low   # insert position

Recursion · L25

def f(n):
    if n == 0:          # base case
        return 1
    return n * f(n - 1) # smaller problem

Trees, DFS · L28

def depth(node):
    if node is None:
        return 0
    return 1 + max(depth(node.left),
                   depth(node.right))

Preorder: node, left, right. Inorder: left, node, right (sorted for a BST).

Graphs · L31

graph.setdefault(a, []).append(b)
def dfs(v):
    visited.add(v)
    for w in graph[v]:
        if w not in visited:
            dfs(w)

Grids: neighbours are up, down, left, right. O(V + E).
